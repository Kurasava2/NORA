# Правила обновления читалки

1. Источник текста — соответствующая глава после литературного прохода.
2. Говорящий определяется по явным словам автора, действию рядом с репликой, контексту, входу и выходу персонажей.
3. Запрещено назначать говорящих по автоматическому чередованию.
4. Неуверенная реплика помечается для ручной проверки, а не угадывается.
5. До представления в главе 10 подпись Лиоры — `Женщина`; после «Лиора Сай» — `Лиора`.
6. После каждого пакета проверяются имена, порядок реплик, пропуски абзацев, внутренние мысли и мобильное отображение.
7. Ключ `localStorage` **`liren-reader-state-v2` не менять**: иначе у читателя сбросится прогресс.
8. Версия в имени HTML не указывается. Историю хранит Git.
