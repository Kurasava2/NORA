# Проверка карт — Вальтерра

## Уже решено

- действующее название государства — **Арвель**;
- **Вальтерра** — устаревшее имя и не используется как активный канон;
- государственные полевые работы Арвеля уже перепроектированы как небольшое координационное бюро и распределённые профильные команды: [[../03 Мир/Организации/Координация государственных полевых работ Арвеля]];
- текстовый канон не может быть отменён старой подписью на карте.

## Что реально осталось проверить

Открыт только визуально-картографический хвост:

- вручную просмотреть растровые карты в `06 Визуальный канон/Карты` на вшитые подписи **«Вальтерра»**;
- проверить SVG и табличные материалы атласа на старое имя и связанные старые подписи;
- при обнаружении заменить или пересобрать конкретный артефакт, не меняя уже утверждённую географию автоматически;
- после полной проверки снять статус `на проверке` с тех карт, которые действительно согласованы с текущими владельцами географии.

Текстовый поиск по текущему GitHub не показывает активных текстовых вхождений «Вальтерра», но это не закрывает растровые изображения, где подпись может быть частью картинки.
