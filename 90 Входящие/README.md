# 90 Входящие

`90 Входящие` — временный рабочий inbox проекта. Он не является источником канона сам по себе.

## Что здесь хранится

- новые материалы, которые ещё не сведены с владельцами областей;
- обнаруженные конфликты, которые ещё требуют решения или проверки;
- очереди переноса, перевода и консолидации, если работа действительно не завершена.

## Что после обработки здесь не остаётся

- полные стенограммы уже разобранных чатов;
- рабочие патчи, уже встроенные в актуальные owner-файлы;
- дубли актуальных заметок;
- старые очереди, пункты которых уже закрыты;
- материалы, сохранённые только ради происхождения решения.

После обработки содержательное решение переносится к владельцу области. Если происхождение важно, в `98 Источники` остаётся короткая сводка с указанием исходника и его Git blob SHA. Полный сырой материал может оставаться в Git-истории или отдельном архиве источников, но не должен бесконечно жить в текущем inbox.

## Текущие активные элементы

- [[Очередь перевода специальных досье]] — только реально незакрытые досье старого англоязычного слоя.
- [[Проверка карт — Вальтерра]] — остаточная ручная проверка старых подписей карт; активное название государства уже закреплено как **Арвель**.
