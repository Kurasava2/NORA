# Паспорт проекта

| Поле | Значение |
|---|---|
| Название | NORA:Эхо возможного |
| Главная героиня | Нора Вейл |
| Язык проекта | русский |
| Текущий основной формат | новелла |
| Возможные дальнейшие форматы | манга, аниме, игра |
| Система заметок | Obsidian + Markdown |
| Версионирование | Git; версии не кодируются в именах активных файлов |
| Главный принцип архива | один факт — один владелец; конфликт виден, а не заметается |

Адаптации не управляют прозой автоматически. При появлении манги, аниме или игры для каждого формата создаётся отдельный слой адаптации, который ссылается на общий канон мира.
