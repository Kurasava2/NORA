# Приоритет источников

При конфликте действует порядок сверху вниз:

1. Последнее прямое решение автора.
2. Текущая проза NORA, текущая читалка и текущие управляющие решения.
3. Специализированные реестры мастера NORA.
4. Фундаменты мира из мастера NORA.
5. Восстановление LIREN и отдельные полные файлы — только для возврата утраченного, если нет конфликта.
6. Архив NAYRA и более ранние материалы — исторические источники.

Нижний слой не может молча отменить верхний. Если нижний слой содержит более подробную версию, она переносится со статусом `на проверке`, пока не подтверждена.
