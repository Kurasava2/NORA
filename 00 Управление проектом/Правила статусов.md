# Правила статусов

| Статус | Значение |
|---|---|
| `канон` | Прямо утверждено автором и обязательно, пока не изменено явно. |
| `утверждено` | Принято для текущей архитектуры или конкретного слоя. |
| `рабочее` | Используется как развиваемая модель; детали можно менять. |
| `на проверке` | Есть ценность, но источник старый, конфликтный или неполный. |
| `конфликт` | Две версии противоречат друг другу; решение ещё не принято. |
| `источник` | Исторический материал, не управляющий текущим каноном. |
| `устарело` | Было рабочим раньше, но заменено более новым решением. |

Статус ставится в свойствах заметки. Старые самоназвания «зафиксировано», «текущее» и «итоговое» сами по себе ничего не повышают.
