## BLOCKED — исчерпывающий аудит входящих ссылок

GitHub code search неоднократно возвращает `incomplete_results: true`, включая запросы по строкам, которые заведомо существуют в мастере.

Следовательно:

- нулевой результат такого поиска **не доказывает отсутствие входящей ссылки**;
- физический перенос нельзя считать безопасным только по code search;
- shell/git CLI не используется как скрытый fallback без прямого разрешения автора.

По этой причине сознательно не выполнены:

1. **Арвель A2** — перенос `03 Мир/Государства и общество/Арвель/` в `.../Государства/Арвель/`;
2. физическая консолидация `Лейвен/001–019`;
3. физическое разнесение технического корпуса;
4. физическое дробление сценовых карт I–III;
5. массовое перемещение карт, CSV-реестров, матриц и визуальных ассетов.

Это не незавершённый content-audit. Блокирован именно **физический слой миграции путей**, для которого требуется полный аудит входящих ссылок и зависимостей.
