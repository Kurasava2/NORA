## BLOCKED — исчерпывающий аудит входящих ссылок

GitHub code search неоднократно возвращает `incomplete_results: true`, в том числе для строк, которые заведомо существуют в мастере.

Следовательно:

- нулевой результат поиска **не доказывает отсутствие входящей ссылки**;
- физический перенос файла нельзя считать безопасным только на основании такого поиска;
- shell/git CLI не используется как скрытый fallback без прямого разрешения автора.

По этой причине сознательно не выполнены:

1. **Арвель A2** — перенос тематического каталога `03 Мир/Государства и общество/Арвель/` в `.../Государства/Арвель/`;
2. физическая консолидация `Лейвен/001–019`;
3. физическое разнесение/перемещение технического корпуса;
4. физическое дробление сценовых карт I–III;
5. массовое перемещение карт, CSV-реестров, матриц и визуальных ассетов.

Это не незавершённый content-audit: содержательные владельцы и границы уже нормализованы. Блокирован именно **рискованный физический слой миграции путей**.
