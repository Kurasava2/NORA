# NORA:Эхо возможного

Чистое рабочее хранилище проекта для Obsidian и Git.

Начинать с файла [НАЧАТЬ ЗДЕСЬ.md](НАЧАТЬ%20ЗДЕСЬ.md). Текущая точка литературного прохода — глава 18; следующий пакет — главы 19–24.

Активные файлы названы по-русски и не содержат номеров версий. Историю версий хранит Git. Полные исходные архивы учитываются в `98 Источники/Реестр исходников.md` и не входят в рабочую историю репозитория.
