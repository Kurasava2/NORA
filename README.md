# NORA:Эхо возможного

Чистое рабочее хранилище проекта для Obsidian и Git. Актуальный `main` — постоянный общий мастер проекта.

Начинать с файла [НАЧАТЬ ЗДЕСЬ.md](НАЧАТЬ%20ЗДЕСЬ.md). Текущая точка литературного прохода — глава 18; следующий пакет — главы 19–24.

Перед крупной правкой и перед коммитом запускать:

```bash
python "08 Инструменты/проверить проект.py"
```

Активные файлы названы по-русски, не содержат номеров версий и используют переносимые между Linux/Android/Windows имена путей. Историю версий хранит Git. Полные исходные архивы учитываются в `98 Источники/Реестр исходников.md` и не входят в рабочую историю репозитория.
