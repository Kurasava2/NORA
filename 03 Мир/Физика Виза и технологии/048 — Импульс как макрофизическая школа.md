ИМПУЛЬС — МАКРОФИЗИКА
======================

1. ОСНОВНЫЕ КООРДИНАТЫ
q, p.

2. ФИЗИЧЕСКОЕ УРАВНЕНИЕ
Без Виза:

dp/dt = F_phys.

С Виз-управлением:
Виз меняет допустимый путь передачи импульса,
но полный физический баланс:

Σp = const

для замкнутой системы.

3. ЭФФЕКТИВНЫЙ КАНАЛ
Импульс особенно эффективен,
если уже существует:
- контакт;
- напряжение;
- движение;
- реакционная опора.

4. СЛАБЫЕ ЗАДАЧИ
- стартовать неподвижную большую массу без опоры;
- долго левитировать;
- удерживать силу без реакции.

5. СВЯЗИ
Импульс <-> Форма:
деформация/напряжение.

Импульс <-> Терма:
удар -> тепло.

Импульс <-> Резонанс:
вибрация/диагностика.

6. БОЙ
Боевая эффективность зависит больше от:
- момента;
- геометрии;
- существующего движения;
чем от максимального Fv.
