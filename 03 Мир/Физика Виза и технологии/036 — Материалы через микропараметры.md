ПОЧЕМУ МАТЕРИАЛЫ ИМЕЮТ РАЗНЫЕ ВИЗ-СВОЙСТВА
==========================================

Материал | g_v | B_v | ℓ_v | τ_v | результат

ВЕЛЛИТ
g_v высокий
B_v низкий
ℓ_v высокая вдоль пластин
τ_v короткая
=> проводник

СЕЛЕН
g_v очень высокий
B_v умеренный
ℓ_v средняя
τ_v длинная
=> буфер

МЕРАЛИТ
g_v высокий локально
B_v низкий
ℓ_v очень короткая
τ_v короткая
=> демпфер

КЕРИТ
g_v очень низкий для структурной перестройки
B_v очень высокий
ℓ_v высокая
τ_v очень длинная
=> стабилизатор

ЭХОЛИТ
g_v высокий у дефектных центров
B_v умеренный
ℓ_v локальная
τ_v крайне длинная
χ_континуум высокая
=> Эхо-сенсор

ТАЛЬ
g_v узкий
B_v высокий вне одной резонансной моды
ℓ_v высокая внутри кристалла
τ_v стабильная
=> частотный эталон

ЛЮМЕНТ
g_v высокий для оптических состояний
χ_люмен высокий
=> оптический исполнитель

САЭРИН
ℓ_v высокая вдоль слоя
ℓ_v мала поперёк
=> анизотропный канал

Главный вывод:
свойства материала не являются набором независимых магических характеристик.
Они следуют из нескольких общих микропараметров.
